# Enterprise Knowledge & Data Intelligence Assistant

An AI-powered enterprise intelligence platform that combines RAG, GraphRAG, LLMs, SQL analytics, and machine learning to answer questions from company documents and structured business data.

## Project Overview

The system allows users to ask questions about enterprise knowledge and business data using natural language.

It can retrieve information from:

- Company policies
- Financial reports
- Product documents
- Research papers
- PDF files
- Excel/CSV datasets
- SQL databases

The system provides intelligent answers along with supporting sources and analytical insights.

## Core Technologies

- Python
- RAG
- GraphRAG
- Large Language Models (LLMs)
- Vector Database
- Knowledge Graph
- SQL
- Data Analytics
- Machine Learning
- Streamlit
